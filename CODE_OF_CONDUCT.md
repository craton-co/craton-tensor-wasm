# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code of conduct.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

This Code of Conduct applies to all project spaces — issues, pull requests, discussions, code reviews, and any official communication channel operated by the project — as well as any public interactions where individuals are representing the project.

## Enforcement

To report unacceptable behavior, contact the project maintainers at:

    security@craton.com.ar

All complaints will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter.
